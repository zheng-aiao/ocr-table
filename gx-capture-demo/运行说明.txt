现场离线运行说明
================

本包已自带 Python 3.12 和全部依赖，现场无需联网、无需安装 Python。

1. 解压整个 gx-capture-demo 目录到任意位置（建议路径不要含中文空格以外的特殊字符）
2. 用记事本编辑 config.yaml：改相机 IP/账号/通道，以及 PI 服务器和账号
3. 双击 run.bat，保持黑色窗口不要关
4. 浏览器打开：http://127.0.0.1:8088/
5. 关闭 run.bat 窗口即停止服务

注意：
- 不要删 python 目录
- 不要用 setup-venv.bat（那是开发机联网装依赖用的）
- data 下 captures / ocr_runs / runs / exports 运行后会自动生成
